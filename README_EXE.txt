ЭКВАЙРИНГ 1С - IMAN и Alif Moliya
==================================

В этой папке:

  IMAN.exe          сверка IMANUM STORE
  AlifMoliya.exe    все открытые заказы Alif Moliya
  credentials\      логины, пароли, ключ Google  -  НИКОМУ НЕ ПЕРЕДАВАТЬ
  ms-playwright\    браузер для сайта Alif (нужен только AlifMoliya.exe)

Папку копировать ЦЕЛИКОМ. Программы ищут credentials и ms-playwright рядом
с собой - по отдельности exe работать не будут.


ЧТО НУЖНО НА НОУТБУКЕ
---------------------
  - Установленная 1С (тонкий клиент). Python НЕ нужен.
  - Интернет.
  - Масштаб экрана Windows лучше 100%, как на основном ноутбуке.


ПЕРВЫЙ РАЗ - ПРОВЕРКА
---------------------
Откройте в этой папке командную строку и выполните:

    IMAN.exe --selftest
    AlifMoliya.exe --selftest

Проверит всё (1С не трогается, в таблицы ничего не пишется) и скажет,
чего не хватает. Должно закончиться словами "Всё готово к работе".


ЗАПУСК
------
Двойной щелчок по exe.

  IMAN.exe          спросит дату "с какой сверять".
                    Enter = с 1-го числа прошлого месяца.

  AlifMoliya.exe    спросит дату.
                    Enter = все открытые заказы без ограничения по дате.

Пока идёт работа - НЕ трогать мышь и клавиатуру: программа сама управляет
окном 1С. Остановить - Ctrl+C (покажет отчёт по уже сделанному).

Запускать по одному. Оба exe одновременно - нельзя, они управляют одним
и тем же окном 1С.

В конце печатается отчёт. Главное в нём - строка "Partial": это заказы,
где в 1С уже что-то проведено, но не доделано, - их нужно проверить руками.
"Skipped" ничего не меняли и подхватятся при следующем запуске.


ЕСЛИ 1С СТОИТ НЕ В ОБЫЧНОМ МЕСТЕ
--------------------------------
Программа ищет 1cv8c.exe в C:\Program Files\1cv8\ сама. Если 1С стоит в
другом месте, допишите в credentials\.env строку с полным путём, например:

    1c_thin_client=D:\1cv8\8.3.22.2283\bin\1cv8c.exe

Или просто откройте 1С и войдите вручную перед запуском - тогда программа
её не запускает, а работает с уже открытой.
